# 后续优化方向（2026-11-05 记录，**尚未实现**）

> 这份文档只记录方向与判断，不代表已开发。当前已发布版本是 **v0.3.5**。

---

## 1. 场景元素坐标标注（优先级最高）

**现状**：6 张房间图都是**静态位图**，代码里只有「窗 / 两盏灯 / 地毯」四个粗略矩形锚点，用来摆特效。

**目标**：把图里的关键物体标出来，让她能"知道东西在哪"：

| 物体 | 说明 |
|---|---|
| 床 | 躺下 / 坐下 / 站在床边 |
| 窗户 | 看雪、看月亮、开窗 |
| 电饭煲 | 去盛饭（人设核心） |
| 书桌 / 显示器 | 坐下工作 |
| 书架 | 找书 |
| 门 | 进出场景 |
| 地毯 | 站着唱歌、转圈 |

**建议格式**（每张图一个 JSON，与图片同名）：

```json
{
  "id": "v2-blue-cozy",
  "size": [760, 760],
  "objects": {
    "window":     { "rect": [16, 5, 33, 36],  "anchor": [32, 40] },
    "bed":        { "rect": [12, 38, 46, 30], "anchor": [34, 58] },
    "riceCooker": { "rect": [69, 30, 9, 8],   "anchor": [73, 40] },
    "desk":       { "rect": [64, 32, 30, 18], "anchor": [78, 50] },
    "rug":        { "rect": [33, 66, 45, 20], "anchor": [55, 76] }
  }
}
```

- `rect` = 物体在图上的包围盒（百分比）
- `anchor` = **落脚点**（角色站/坐的位置），这才是移动的目标

**怎么标注**：复用已有的调试模式（长按「🖼 换景」），把它从「4 个特效框」扩展成「多物体框 + 下拉选择 + 导出 JSON」。

## 2. 角色可定位移动

**现状**：角色是一个 320px 的 webm，固定居中，只能整体 `translateX` 微调。

**目标**：能走到指定物体前（走到电饭煲前、跳上床、坐椅子上）。

要改的点：

1. **位置改用百分比锚点**（现在窗口 resize 之后位置会偏）
2. **近大远小**：走到房间后部时缩小一点，深度感更真实
3. **走位动画**：CSS `transition` 平移够用；复杂的话按路径插值（先横后纵，避免穿模）
4. **朝向**：目前 webm 没有朝向区分，真要做得换 Live2D 或补左右两套素材

调用形如 `moveTo('riceCooker')` → 读标注里的 anchor → 平移 + 缩放。

## 3. Aurabot 通道打通：她自己切场景 + 自己走位

**现状**：模块里只有一个 `whale_anim` 工具（换动作），房间只能用户点按钮切。

**目标工具**：

| 工具 | 作用 |
|---|---|
| `whale_room(id \| next)` | 切换房间（她可以说"我去厨房等你"然后切过去） |
| `whale_walk(target)` | 走到某个物体前（配合标注） |
| `whale_scene({room, walk, anim})` | 组合动作：换房间 + 走位 + 做动作 |

**通道设计**：沿用现有 `pending → /anim/poll` 的轮询机制最简单（窗口每 0.9 秒问一次）；要更实时可以换 SSE / WebSocket。

**需要理顺的状态归属**：现在房间选择存在窗口的 `localStorage`，她那边看不到。要做"她自己切"，得把当前房间、角色位置**收到后端状态**里，两边共用一个真源。

---

## 4. 素材分层（中期，可选）

- 静态整图 → **分层**（背景 / 家具 / 角色 / 前景遮挡），能做遮挡和景深
- 或者直接上 **3D 场景**（Three.js + 低模），坐标天然存在、相机可控
- 现实建议：先用「标注 + 2D 位移」验证玩法，够用了再考虑上 3D，不然成本会翻几倍

---

## 5. 其他加分项

- **时间联动**：白天 / 夜晚按系统时间自动换图（已有 `l1-bright-nordic` 白天图）
- **动作与场景匹配**：她吃白饭时自动切到厨房 / 餐桌场景
- **场景包开放**：让用户自己加图 + 标注，做成可扩展的资源格式
- **NPC**：房间里放第二只小鲸鱼（静态图 + 标注就能实现）

---

## 建议的落地顺序

1. **元素坐标标注**（纯数据 + 调试工具扩展，风险低、收益最大）
2. **模块通道**（先只做 `whale_room`，把状态收到后端）
3. **角色走位**（读标注 anchor，先做瞬移，再做平滑移动）
4. **素材分层 / 3D**（看第 1~3 步的效果再定）

---

## 落地前要注意

- **标注与图片必须同源**（同一个房间 id），换图就得重标
- 角色移动用百分比锚点，天然适配窗口缩放
- 公开发布时的**素材授权**：目前房间图是本地用 Codex 生成的，商用条款还需要确认
- 现在的特效锚点（窗 / 灯 / 地毯）未来应该并入同一份标注文件，不要两套坐标各管各的
